# Security Policy

## Supported versions

Security fixes are applied to the latest tagged release and the default branch.

## Report a vulnerability

Use the repository's private security advisory form. Do not open a public issue for a suspected vulnerability and do not include credentials, tokens, private profiles, or private repository content in a report.

Include the affected release, reproduction steps, impact, and the smallest safe example.

TruthLint processes local repository text. Treat any skill installation as executable tooling, inspect the source, pin a release when possible, and verify its checksum before use in sensitive repositories.
